
### ChronoTally

time tracking and timesheet management.

### Installation

You can install this app using the [bench](https://github.com/frappe/bench) CLI:

```bash
cd $PATH_TO_YOUR_BENCH
bench get-app $URL_OF_THIS_REPO --branch version-15
bench install-app chronotally
```

### Branches

ChronoTally follows the standard Frappe branching convention. Each branch is a production line for one Frappe/ERPNext major version:

- `version-16` — production for Frappe/ERPNext v16. Default branch; new work and PRs target this branch.
- `version-15` — production for Frappe/ERPNext v15. Maintained with fixes backported from `version-16`.

For v16 installs use `--branch version-16`.
